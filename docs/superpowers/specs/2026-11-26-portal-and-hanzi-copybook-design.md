# 快樂學習小教室：入口首頁與國小生字字帖練習設計規格

- **日期**：2026-11-26
- **目標專案**：`peiankuo-tw/zhuyin`（GitHub Pages 公開靜態網站）
- **核心目標**：將現有直接進入注音練習的靜態網站升級為具備「入口首頁」的多工具學習站，完整保留既有注音描線小教室，並新增「國小生字字帖小教室」（支援線上互動描寫與 A4 列印字帖，內建康軒／南一／翰林 1～6 年級字庫與自訂輸入）。

## 1. 整體架構與目錄規劃

維持純靜態前端架構（HTML + Tailwind CSS CDN + Vanilla ES Modules / JS），零建置步驟，push 到 `main` 分支即透過 GitHub Pages 自動上線。

```text
zhuyin/
├── index.html                        # 入口首頁（快樂學習小教室）
├── zhuyin/
│   └── index.html                    # 現有「快樂學注音・描線小教室」（頂部新增「回首頁」按鈕）
├── hanzi/
│   ├── index.html                    # 全新「國小生字字帖小教室」（線上描寫 + A4 列印）
│   ├── app.js                        # 主介面控制、選字狀態、自訂清單、列印預覽渲染
│   ├── canvas.js                     # 互動描寫畫布、教育部筆順動畫、筆刷與完成進度
│   ├── stroke-service.js             # 教育部筆順 JSON + 萌典注音/部首查詢與快取
│   └── print.css                     # A4 列印專用樣式（@media print）
└── data/
    ├── index.json                    # 版本與年級索引（康軒 / 南一 / 翰林 × 1~6 年級）
    ├── kangxuan-1.json ... kangxuan-6.json
    ├── nanyi-1.json    ... nanyi-6.json
    └── hanlin-1.json   ... hanlin-6.json
```

## 3. 國小生字字帖小教室（`hanzi/`）功能設計

頂部導覽列包含「🏠 首頁」按鈕、標題，以及兩大模式切換分頁：
- **✍️ 線上描寫**
- **🖨️ A4 列印字帖**

兩模式共用同一份「目前生字清單（Active Character List）」，使用者選完課次或貼完生字後可無縫切換練習或列印。

### 3.1 選字與自訂生字區
提供兩個分頁切換字源：
1. **📚 課本版本選字**：
   - 四層連動下拉選單：**版本**（康軒 / 南一 / 翰林）→ **年級**（1～6 年級）→ **學期**（上學期 / 下學期）→ **課次**（第 1 課～末課，含課名）。
   - 顯示該課生字條，可「全選整課」或點選個別字進行開關（勾選要練習／列印的字）。
   - 提供「✏️ 帶入自訂區微調」按鈕，一鍵將該課生字複製到自訂輸入框，方便家長配合當年度課本微調增刪生字。
2. **✍️ 自訂輸入生字**：
   - 文字輸入框支援直接輸入或貼上任意國字／詞語，自動過濾非中文字元（保留 CJK 統一表意文字），提供「去除重複字」開關（預設開啟）。
   - 支援「💾 儲存成我的清單」（儲存在 `localStorage` 鍵 `hanzi_custom_lists_v1`，可命名如「小二上 第 5 課 訂正字」並隨時載入或刪除）。

### 3.2 模式一：✍️ 線上互動描寫（`canvas.js`）
- **生字資訊卡**：
  - 顯示當前生字（楷書大字）、**台灣標準直式注音**（含二／三／四聲與輕聲符號正確擺位）、部首、總筆畫數。
  - 若該字為**破音字**（萌典回傳多組讀音），在注音旁提供「切換讀音」小鈕，切換後同步記憶到當前練習與列印字帖。
  - 提供「🔊 唸出來」按鈕，透過 `window.speechSynthesis`（優先 `zh-TW` 語音）朗讀該字。
- **互動描寫畫布**：
  - 支援滑鼠、手指觸控與觸控筆（`PointerEvent` + `touch-action: none` 防捲動）。
  - 底格切換：**九宮格**（預設）、**十字格**、**米字格**。
  - 筆順功能：
    - **▶ 播放筆順**：依台灣教育部標準筆順一筆一畫動畫示範（支援慢速／正常速度）。
    - **👣 單步筆順**：每次點擊前進一筆，高亮當前筆畫方向與起點。
    - **淡色描紅開關**：可切換顯示／隱藏淡色底字，進階練習可關閉底字默寫。
  - 筆刷工具列：黑／紅／藍／彩虹筆、筆畫粗細滑桿、復原上一筆、清除重寫。
  - 成就回饋：「⭐ 寫好了！」按鈕觸發蓋章動畫、慶祝紙花，並將該字記錄到 `hanzi_practice_progress_v1`。
- **生字切換列**：底部列出本次清單的所有生字，已完成的字顯示金星標記，支援上一字／下一字快速切換。

### 3.3 模式二：🖨️ A4 列印字帖（`print.css` + 預覽器）
- **列印設定面板**（調整後即時更新下方 A4 預覽）：
  - **字帖標題**：自動帶入課次名稱（如「康軒 三年級上學期 第 1 課 生字練習」），支援自由編輯；表頭右側固定含「班級：＿＿＿ 座號：＿＿ 姓名：＿＿＿＿ 日期：＿＿/＿＿」欄位。
  - **格線樣式**：九宮格（預設）、十字格、米字格。
  - **格型大小**：標準（每列 8 格，每頁 10 列，適合中高年級）或大格（每列 6 格，每頁 8 列，適合低年級）。
  - **描紅格數**：0～5 格可調（預設 2 格淡紅描紅＋其餘空白格）。
  - **輔助資訊開關**：是否顯示直式注音格（預設開）、是否顯示部首與總筆畫（預設開）。
- **列印輸出規範（`@media print`）**：
  - `@page { size: A4 portrait; margin: 10mm; }`
  - 隱藏所有網頁導覽列、設定面板、按鈕與背景點點，僅保留純白 A4 字帖頁面。
  - 使用 `break-inside: avoid` 確保每一列字帖完整不分斷，超過單頁列數自動換頁並於新頁保留精簡表頭。

## 4. 資料來源、模組邊界與錯誤處理

### 4.1 模組職責邊界
| 模組 | 職責 | 公開介面 / 依賴 |
| --- | --- | --- |
| `hanzi/stroke-service.js` | 取得單字教育部筆順資料與萌典注音／部首／筆畫，並管理快取 | `getCharStrokeData(char)`、`getCharMeta(char)`；無 DOM 依賴 |
| `hanzi/canvas.js` | 負責單一畫布的格線繪製、筆順動畫、手寫筆跡、復原與清除 | `HanziCanvas` 類別；僅依賴傳入的 `<canvas>` 與筆順資料 |
| `hanzi/app.js` | 協調版本字庫載入、自訂生字、模式切換、A4 預覽渲染與狀態持久化 | 依賴 `stroke-service.js`、`canvas.js` 與 `data/*.json` |

### 4.2 外部資料來源與快取
1. **教育部標準筆順**：透過開源 CDN 載入 `c9s/zh-stroke-data`（中華民國教育部常用國字標準字體筆順學習網資料）單字 JSON（`https://cdn.jsdelivr.net/gh/c9s/zh-stroke-data@master/json/<hex>.json`），並快取於記憶體中。
2. **萌典注音與部首**：查詢 `https://www.moedict.tw/uni/<char>.json`（CORS 支援），解析 `heteronyms[].bopomofo`、`radical`、`stroke_count`，結果存入 `localStorage`（`hanzi_moedict_cache_v1`，上限保留最近 500 字避免超過配額）。
3. **跨裝置楷書字型**：CSS 字型堆疊為 `DFKai-SB, BiauKai, "標楷體", "LXGW WenKai TC", serif`，並透過 Google Fonts 載入 `LXGW WenKai TC` 確保 iPad / Android / Linux 皆能顯示與列印正統繁體楷書。

### 4.3 課本版本字庫結構（`data/`）
- `data/index.json`：定義三大版本（`kangxuan`、`nanyi`、`hanlin`）與 1～6 年級清單。
- `data/{publisher}-{grade}.json`（共 18 檔）：
  ```json
  {
    "publisher": "kangxuan",
    "publisherName": "康軒",
    "grade": 1,
    "semesters": {
      "1": [
        { "lesson": 1, "title": "第一課 拍拍手", "chars": "拍手一起玩" }
      ],
      "2": [
        { "lesson": 1, "title": "第一課 春天來了", "chars": "春天花開風" }
      ]
    }
  }
  ```

### 4.4 錯誤處理與退路（Graceful Degradation）
- **筆順 CDN 失敗或無收錄該字**：自動降級為「淡色楷書描紅底字」模式，畫布照常可手寫描紅，介面溫和顯示「此字無筆順動畫，可直接描紅練習」，絕不中斷操作。
- **萌典 API 無法連線**：注音格改顯示空白（允許使用者手動略過或直接描寫國字），不阻擋畫布與列印。
- **空清單防呆**：若目前清單為空，線上描寫區顯示引導提示、列印按鈕設為停用狀態。
- **`localStorage` 不可用或滿額**：所有讀寫皆以 `try/catch` 包裝，失敗時自動改以記憶體狀態運行。

## 5. 驗證與測試計畫

實作完成後，在本機啟動靜態 HTTP 伺服器進行完整驗證：
1. **首頁入口**：檢查 `index.html` 桌面／手機響應式排版、兩張功能卡片導覽連結、以及正確讀取既有的 `zhuyin_practice_progress_v2` 進度。
2. **注音教室回歸測試**：開啟 `zhuyin/index.html`，確認描寫畫布、筆順動畫、音效與「🏠 首頁」返回鈕皆正常運作。
3. **國小字帖功能測試**：
   - 依序測試康軒／南一／翰林 1～6 年級上下學期課次載入與選字。
   - 測試「帶入自訂區微調」、自訂貼上含標點文字過濾、儲存與刪除自訂清單。
   - 測試線上描寫畫布（九宮格／十字格／米字格、教育部筆順動畫、單步筆順、破音字切換、手寫筆刷與星星蓋章）。
   - 測試 A4 列印預覽切換（標準格／大格、描紅格數、注音開關）與列印媒體樣式（無多餘 UI、分頁不切斷字列）。
